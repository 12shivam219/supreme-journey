# Tracker Android Background Agent (Kotlin)

A production-ready Android companion application targeting Android 8.0+ (API 26+) for direct APK sideloading and transparent device activity tracking.

---

## Architecture & Features

1. **Persistent Transparency Foreground Service (`TrackerForegroundService.kt`)**:
   - Runs an ongoing, non-dismissible notification stating: *"Tracker is Active: Monitored with parent visibility"*.
   - Automatically restarts on boot via `BootReceiver`.

2. **Usage Tracking Engine (`UsageStatsHelper.kt` & `TrackerAccessibilityService.kt`)**:
   - Uses Android's `UsageStatsManager` to accurately compute application foreground intervals.
   - Optional `AccessibilityService` listens to `TYPE_WINDOW_STATE_CHANGED` for near-real-time application launch detection.

3. **Offline-First Room Database (`AppDatabase.kt` & `AppSessionDao.kt`)**:
   - Buffers session records locally in a SQLite/Room database.
   - Syncs every 15 minutes using `WorkManager` (`TelemetrySyncWorker.kt`) with network constraints.
   - Retries automatically on reconnect; zero data loss during offline periods.

4. **Transparent Setup Wizard & QR Pairing (`SetupWizardActivity.kt`)**:
   - Integrated camera QR scanner (ZXing) to scan pairing codes generated by the parent web dashboard.
   - Step-by-step permission walkthrough for **Usage Access**, **Accessibility Event Detection**, and **Battery Optimization Exemption**.
   - Child transparency dashboard (`MainActivity.kt`) displaying today's total active hours, app breakdown, and manual sync controls.

5. **Release Build & ProGuard Rules**:
   - Configured `build.gradle.kts` with ProGuard minification, resource shrinking, and signing configuration.

## Step-by-Step Sideload Installation Guide for Parents

Since this app is distributed directly as a standalone APK rather than through the Google Play Store, follow these steps to install and set up Tracker on your child's Android device:

### Step 1: Build or Transfer the APK
1. Build the release APK:
   ```bash
   cd apps/android-agent
   ./gradlew assembleRelease
   ```
2. The generated APK will be located at:
   `apps/android-agent/app/build/outputs/apk/release/app-release.apk`
3. Transfer `app-release.apk` to your child's phone via USB cable, Google Drive, or local file sharing.

---

### Step 2: Enable "Install Unknown Apps" on the Child's Phone
1. Open **Settings** on the Android device.
2. Go to **Apps** > **Special App Access** > **Install Unknown Apps** (or search for *"Unknown apps"* in the Settings search bar).
3. Select the app you used to download the file (e.g., **Files by Google**, **Chrome**, or your file manager) and toggle **Allow from this source** to **ON**.

---

### Step 3: Install the Tracker App
1. Open the file manager on the phone, tap on `app-release.apk`, and tap **Install**.
2. If Google Play Protect displays a prompt stating *"Blocked by Play Protect"*, tap **More Details** > **Install Anyway** (this occurs for all non-Play Store sideloaded APKs).

---

### Step 4: Complete the Pairing & Permissions Wizard
1. Open the **Tracker** app on the child's phone.
2. In your Parent Web Dashboard, navigate to **Family Accounts** > **Pair New Device** for the child to reveal their **Pairing QR Code** and 6-digit code.
3. On the phone, tap **Scan QR Code** (or manually type the 6-digit pairing code).
4. Tap **Grant Usage Access**:
   - The app will open Android's **Usage Access** settings.
   - Find **Tracker** in the list and toggle **Permit usage access** to **ON**.
5. *(Optional)* Tap **Enable Event Detection** to turn on the Accessibility Service for real-time window tracking.
6. Tap **Complete Setup & Link**.

---

### Step 5: Verification
1. The app will transition to the **Transparency Dashboard** showing today's logged screen time.
2. A persistent notification will appear in the Android notification shade: *"Tracker is Active"*.
3. Refresh your Parent Web Dashboard on your computer or tablet—the Android device will now display as **Online** with real-time app telemetry.
